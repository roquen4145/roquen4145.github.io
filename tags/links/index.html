외부 링크 작성 가이드

언제 외부 링크를 거는가 근거 자료가 블로그 외부에 있을 때만 사용한다. 내부 개념은 최대한 relref로 연결한다. 작성 규칙 일반 Markdown 링크로 작성한다: [텍스트](https://example.com) (relref/ref는 내부 링크 전용) 링크 텍스트는 목적을 설명한다. “여기” 같은 모호한 앵커는 피한다. 추적 파라미터(utm 등)는 제거한다. 단순 URL만 남긴다.
