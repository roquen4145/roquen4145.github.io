2026-01-17 · 마지막 수정 2026-01-19

원칙: 최소 추적 개인 식별 없이 필요한 지표만 수집한다. 쿠키 배너 없이 동작하며, 광고/리마케팅 목적 추적은 하지 않는다. 수집하는 데이터 페이지뷰, 인기 글, 유입 경로, 검색 유입 여부. 수집하지 않는 데이터 개인 식별 정보, 위치 추적, 리마케팅용 식별자, 광고 성과 데이터.

원칙: 최소 추적

  • 개인 식별 없이 필요한 지표만 수집한다. 쿠키 배너 없이 동작하며, 광고/리마케팅 목적 추적은 하지 않는다.

수집하는 데이터

  • 페이지뷰, 인기 글, 유입 경로, 검색 유입 여부.

수집하지 않는 데이터

  • 개인 식별 정보, 위치 추적, 리마케팅용 식별자, 광고 성과 데이터.

쿠키/개인식별 정책

  • 쿠키는 사용하지 않거나 비식별 집계용에 한정한다. 식별 가능한 데이터는 저장하지 않는다.

도구 삽입 위치(개요)

  • 추적 스크립트는 레이아웃 하단에 삽입한다. 현재는 Plausible의 cookieless 스크립트를 data-domain으로만 설정해 사용한다.

참고

  • 운영 원칙은 Quiet Systems 개요와 PR 기반 운영과 자동화를 따른다.
  • 글 작성 시 규칙은 작성 규칙을 준수한다.
