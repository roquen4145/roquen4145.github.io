Quiet Systems 개요

2026-01-17 · 마지막 수정 2026-01-19

목적 Quiet Systems는 Working Memos로 운영되는 개인 지식 그래프다. 도구보다 사고의 흐름을 남기는 데 집중한다. 무엇을 담는가 / 담지 않는가 담는 것: 개념 노드, 연결 관계, 판단의 근거. 담지 않는 것: 시계열 일기, 광고성 글, 미완성 메모. 용어 정의 Memo: 하나의 개념 또는 생각 노드.

meta overview

목적

  • Quiet Systems는 Working Memos로 운영되는 개인 지식 그래프다. 도구보다 사고의 흐름을 남기는 데 집중한다.

무엇을 담는가 / 담지 않는가

  • 담는 것: 개념 노드, 연결 관계, 판단의 근거.
  • 담지 않는 것: 시계열 일기, 광고성 글, 미완성 메모.

용어 정의

  • Memo: 하나의 개념 또는 생각 노드.
  • Hub: 여러 Memo를 묶어 맥락을 제공하는 중심 글.
  • Meta: 블로그 운영 규칙과 구조를 설명하는 문서 영역.

시작하기

  • 읽기: 읽는 법 가이드에서 탐색 경로를 확인한다.
  • 검색: 상단 검색창은 relref 링크로 연결된 노드를 우선 보여준다.
  • 토픽 진입: 토픽 지도에서 영역을 선택한다.
  • 운영 규칙: 작성 규칙과 PR/자동화를 참고한다.
