외부 링크 작성 가이드

2026-01-17 · 마지막 수정 2026-01-19

언제 외부 링크를 거는가 근거 자료가 블로그 외부에 있을 때만 사용한다. 내부 개념은 최대한 relref로 연결한다. 작성 규칙 일반 Markdown 링크로 작성한다: [텍스트](https://example.com) (relref/ref는 내부 링크 전용) 링크 텍스트는 목적을 설명한다. “여기” 같은 모호한 앵커는 피한다. 추적 파라미터(utm 등)는 제거한다. 단순 URL만 남긴다.

언제 외부 링크를 거는가

  • 근거 자료가 블로그 외부에 있을 때만 사용한다. 내부 개념은 최대한 relref로 연결한다.

작성 규칙

  • 일반 Markdown 링크로 작성한다: [텍스트](https://example.com)
    (relref/ref는 내부 링크 전용)
  • 링크 텍스트는 목적을 설명한다. “여기” 같은 모호한 앵커는 피한다.
  • 추적 파라미터(utm 등)는 제거한다. 단순 URL만 남긴다.

품질 기준

  • 링크를 추가하는 문장에 요약을 포함해 클릭하지 않아도 맥락을 알 수 있게 한다.
  • 가능하면 1차 소스(원 논문/공식 문서)에 링크한다.

참고

  • 내부 링크 규칙은 작성 규칙을 따른다.
  • 개인정보/추적 정책은 프라이버시와 트래픽 분석을 참고한다.
  • 읽는 흐름은 Quiet Systems 읽는 법을 확인한다.
