## 글 템플릿 (필수)

```md
## 왜 이걸 정리하는가
## 핵심 개념 (잊지 말아야 할 것)
## 내 생각
## 연결된 글
```

## 사실 vs 의견 분리

- 사실은 `핵심 개념`에, 의견·해석은 `내 생각`에 쓴다. 문단을 섞지 않는다.

## 링크 규칙

- 내부 링크는 `relref`/`ref`만 사용한다.
- 각 글은 최소 2개의 기존 글을 참조하고, `연결된 글`에 확장/반대 관점 링크를 1개 이상 포함한다.

## 토픽 분류 규칙

- 현재 토픽은 [토픽 지도]({{< relref "/meta/topic-map" >}}) 기준에 맞춘다. 겹칠 경우 더 추상적인 토픽(허브) 쪽으로 배치한다.

## 금지사항

- 본문 중간 광고, 과한 강조(깜박임/팝업), URL 하드코딩, 날짜 기반 경로 사용 금지.
